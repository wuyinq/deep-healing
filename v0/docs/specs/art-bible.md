## 1. 配色（可执行）

| 项 | 约束 | 取值来源 / 检查方式 |
|---|---|---|
| 主色板 | `assets/manifest.json` 的 `palette_id`，最多 6 色 | `tools/aesthetic_check.py` 校验 |
| 饱和度 | **≤ 45**（HSV 的 S，0–100） | 同上（实测值 22，见 `spikes/s3-render/logs/png_stats.log`） |
| 色相范围 | 暖区 `20°–60°`（米 / 木 / 奶油）为主；冷色仅用于夜 / 雨场景且 ≤ 2 个色板槽 | 色板 JSON 逐色声明 |
| 对比度 | 相邻主色明度差 `≤ 35`（L，0–100） | 色板计算 |
| 高饱和色 | **禁用**（S > 45 的颜色不得出现在任何主色板） | `aesthetic_check.py` 非 0 即拒 |

## 2. 光照（可执行）

| 项 | 约束 |
|---|---|
| 色温 | `3200 K – 5200 K`（黄昏到阴天）；单场景内 ≤ 2 个色温值 |
| 主光强度 | `0.6 – 1.4`（引擎相对单位）；环境光 `0.25 – 0.6` |
| 阴影 | `shadowMap = true`；**接触阴影证据**需在画面级度量中可见（亮度差 ≥ 8，见 `png_stats.py` 的采样口径） |
| 雾 / 深度 | `fog.near = 40`、`fog.far = 120`（参数级）；**画面级可见性**属未证实项（AC-11 GAP） |
| 时间一致性 | 同一场景的光照参数在同一 tick 内**不得**由 wall-clock 派生（`snapshot.schema.json` 既有条文） |

## 3. 材质（可执行）

| 项 | 约束 |
|---|---|
| 粗糙度 `roughness` | `0.55 – 0.95`（偏哑光；镜面高光禁用） |
| 金属度 `metalness` | `0.0 – 0.15` |
| 贴图分辨率 | `≤ 2048×2048`（V0 占位资产为程序化 64×64，无贴图） |
| 法线强度 | `≤ 0.4`（避免硬朗起伏） |

## 4. 镜头（可执行）

| 项 | 约束 |
|---|---|
| FOV | `35° – 55°`（人眼近似；广角畸变禁用） |
| 相机高度 | `1500 mm – 1800 mm`（成人视高） |
| 距离 | 主被摄体 `2000 mm – 12000 mm` |
| 运动 | 仅缓入缓出；**禁用**快速推拉 / 摇晃（与治愈系基调冲突） |

## 5. 音频基调（可执行）

| 项 | 约束 |
|---|---|
| BPM | `60 – 84` |
| 响度 | 整轨 `-16 LUFS ± 2`；峰值 `≤ -1 dBTP` |
| 频段 | 高频（> 8 kHz）能量占比 `≤ 12%`；禁用突发瞬态 |
| 来源许可 | 只允许可商用权重（`asset.license.table.data.json`：`ACE-Step` Apache-2.0 ✓；**MusicGen 权重 CC-BY-NC ✗**） |

## 6. UI 风格（可执行）

| 项 | 约束 |
|---|---|
| 间距 | 8 pt 网格（`8 / 16 / 24 / 32`） |
| 圆角 | `4 – 12 px` |

## 7. 风格锁定（三选多，给选择规则）

| 方案 | 适用 | 选择规则 | 登记方式 |
|---|---|---|---|
| **角色参考表**（必需） | 所有角色类资产 | 每个角色 ≥ 3 张参考图（正面 / 侧面 / 场景内）；跨资产颜色偏差 ≤ ΔE 5 | `asset.manifest` 的 `derived_from` 指向参考图资产 |
| **LoRA**（可选） | 需要强统一风格时 | 仅当角色参考表 + 提示词模板不足以把偏差压到阈值内才启用；LoRA 训练数据必须是**自有 / 可商用** | LoRA 权重作为资产登记（`type=3d`→ 不适用；用 `text` 占位 + `meta.note`） |
| **参考图**（可选） | 单张风格锚定 | 仅在无角色一致性要求时使用 | 同上 |
| **提示词模板**（必需） | 全部 | 模板进受管产物（sha256 登记）；实际提示词只存 `prompt_digest` | `asset.manifest.workflow` |

## 8. 角色一致性（可检查项）

1. **颜色**：同一角色跨资产的主色 ΔE ≤ 5（超限即重生成，不得靠后期修）。
2. **比例**：身高 / 头身比偏差 ≤ 5%。
3. **服装要素**：角色参考表登记的 `fixed_attributes`（如「灰蓝外套」「圆形眼镜」）在每张资产中必须出现。
4. **检查方式**：`tools/aesthetic_check.py`（数值级）+ 人工过审（`review_status=adopted` 的 `review.note` 逐条记录偏差）。

## 9. 与 `01 §10` 的一致性

- 本文件的数值约束与 `01 §10`（AC-11 美学与双模式 IA）同基调：低饱和、暖色、无强对比、无镜面。
- `assets/manifest.json` 的既有数值（`saturation_max=45` 等）保持不变；本文件不引入新的冲突阈值。

## 10. 明确不做（防误读）

- **不**宣称「治愈系氛围已达成」（AC-11 仍 GAP：只有配置级 + 一张占位场景截图 + 画面级度量）。
- **不**在 V0 量产素材（只需 1 张程序化占位资产 + 1 份 manifest 示例）。
- **不**使用任何不可商用权重（FLUX.1-dev / MusicGen 权重等）。
